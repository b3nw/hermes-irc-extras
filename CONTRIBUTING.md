# Contributing Guidelines

Thanks for contributing to `hermes-irc-extras`!

## Code Standards

- Indentation: 4 spaces for Python, 2 spaces for JSON/YAML.
- Line length: limit to 100 characters.
- Ruff/Linter: keep all python code lint-free.
- Type hints: include typing annotations for all public interfaces.

## Running Tests

Verify all tests pass before making pull requests:

```bash
pytest tests/test_irc_extras.py
```
